# Hireboard

A Vite + React + TypeScript job marketplace dashboard with three role-based workspaces:

- Job seeker: job discovery, saved jobs, applications, and profile progress.
- Company: hiring overview, active role performance, applicant flow, and job posting modal.
- Admin: marketplace health, moderation queue, user/job metrics, and activity.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
